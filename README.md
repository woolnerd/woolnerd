# Hi, I'm Dave.

I'm a full-stack and AI product engineer in the NYC metro area. I build client automation systems and early-stage products, usually when the requirements are still messy and someone needs to make the whole thing work.

Before moving into software, I worked in film and television set lighting. That taught me to troubleshoot under pressure, learn unfamiliar systems quickly, and work well with people who have very different jobs from mine. It turns out those skills travel.

These days my work is mostly TypeScript, React, and PostgreSQL, plus Python for AI work. I also have production Ruby on Rails experience from my time at Voray.

## A few things I've built

- [Tweak](https://github.com/woolnerd/tweak-app): lighting control for iPhone and iPad, built with React Native and TypeScript. Brings professional sACN lighting workflows to a smaller, more portable interface.
- [FTAI Voice Agent](https://github.com/woolnerd/ftai-voice-agent): a self-hostable real-time voice agent built with LiveKit and interchangeable speech and language-model providers.
- [Cited Doc QA](https://github.com/woolnerd/cited-doc-qa): document Q&A with hybrid search, reranking, source citations, automated tests, and deployment tooling.
- [Media QC Agent](https://github.com/woolnerd/media-qc-agent): quality supervision for AI-generated media pipelines. Deterministic gates catch defects first, a model interprets only what the gates miss, and humans approve scoped repairs that run through durable, idempotent jobs. Documented guarantees, ADRs, and model evals.
